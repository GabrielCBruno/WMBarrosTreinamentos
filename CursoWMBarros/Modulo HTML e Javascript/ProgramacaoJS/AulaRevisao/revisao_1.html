Módulo Extra - Atividades Práticas

Variáveis em JS

1. Declarar todos os tipos de variáveis estudados, como constantes e variáveis.
2. Como constantes utilizar const e iniciar na declaração.
3. Como variáveis utilizar let e iniciar sem valor, definir depois.
4. Criar alert explicando cada tipo e exemplificar concatenando com o valor da variável declarada.
5. Exercitar Number, String, Bool, toFixed(), parseFloat()
6. Criar alert exibindo os valores transformados.

Formulário

Nenhum formulário é requerido para este exercício.
