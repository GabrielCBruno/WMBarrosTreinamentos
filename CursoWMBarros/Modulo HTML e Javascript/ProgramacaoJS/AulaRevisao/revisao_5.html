Módulo Extra - Atividades Práticas

Condicionais com Operadores Relacionais

1. Validar se os campos do formulário estão vazios ou preenchidos.
2. Validar se o valor dos campos numéricos são, de fato, números.
3. Validar se a senha cadastrada é igual à confirmação de senha.
4. Verificar se a senha tem caracteres o suficiente, trabalhando com máximo e mínimo, utilizando o length.
5. Verificar se o jogador cadastrado tem idade suficiente e não excede a idade máxima para jogar o jogo.
6. Caso algo esteja incorreto, exiba no HTML o erro.
