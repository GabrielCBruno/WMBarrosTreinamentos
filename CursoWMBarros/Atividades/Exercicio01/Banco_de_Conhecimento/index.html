O que é HTTP e HTTPS

HTTP e o HTTPS são regras de comunicação usadas para transferir dados entre o seu navegador e os sites na internet. A principal diferença é que o HTTP envia dados em texto puro e sem proteção, enquanto o HTTPS adiciona uma camada de criptografia para manter suas informações seguras contra roubos e invasões.

O que é IP

Internet Protocol ou Protocolo de Internet é um número único de identificação atribuído a cada computador, celular, roteador ou outro dispositivo conectado a uma rede. Ele funciona como o endereço de uma casa ou um número de documento, permitindo que os dados enviados pela internet encontrem o destino correto.

O que são Portas

é um número virtual que ajuda o computador a entregar os dados recebidos da internet para o programa ou aplicativo certo. Se o endereço IP é como o número de um prédio, a porta de rede é como o número do apartamento.

O que é Docker

O Docker é uma plataforma de código aberto para criar, executar e gerenciar aplicações usando containers. Ele empacota um programa com tudo o que ele precisa para funcionar (códigos, bibliotecas e ajustes) em um único pacote leve, garantindo que o software rode igualzinho em qualquer computador.

O que é Container e Imagem Docker

Uma imagem Docker é um modelo estático e somente leitura que guarda o código, as bibliotecas e as regras de um programa. Um contêiner Docker é a cópia ativa dessa imagem rodando em uso real. Pense na imagem como a receita de um bolo e no contêiner como o bolo pronto para comer.
